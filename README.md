### 🤖 What I've Been Building

```text
├── RAMMP Platform (ROS 2 Humble, Ubuntu 22.04)
│   ├── Sensor integration — RealSense D435i (wrist cam) + Orbbec Gemini 336L (nav cam)
│   ├── EKF-based sensor fusion for robust state estimation
│   ├── URDF/xacro robot description authoring
│   ├── ROS 2 Python launch architecture for multi-sensor bringup
│   └── Jetson Orin NX deployment via Docker-based SDK Manager
│
├── MeBot
│   └── 4-motor IMU-based tilt control system, PID loop for pitch stabilization
│
└── Tooling & Workflow
    ├── CI/CD pipelines with GitHub Actions
    ├── Pre-commit hooks (black, ruff, clang-format, mdformat)
    └── Issue-driven branching + PR review workflows
```
